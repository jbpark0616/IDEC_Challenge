지정주제: Winograd 변환 zero 행의 원인 분석
==========================================
측정: scripts/report_data/designated_sparsity.py
최종 verilog/ 파일은 수정하지 않았다. 실행 전후 지정주제 SHA256 manifest와 대조했다.
input_1000.txt는 100개 고유 이미지가 같은 순서로 10회 반복된다.
고유 100장을 RTL로 실행했고 97/100 정답, 정수 참조 모델과 불일치 0으로 PASS했다.
1000개 독립 표본으로 표현하면 안 된다.

측정 경계
입력 변환기의 in_valid && in_ready에서 입력 d를 기록하고,
out_valid && out_ready에서 V와 마스크를 기록했다.
이미지·레이어별 순서대로 대응시켜 총 21,900개 채널 타일의 V 16원소 및
4비트 마스크를 Python의 정확한 정수 변환과 모두 비교했다. 불일치 0.
출력 채널 재사용 횟수로 가중하지 않은, 최초 생성된 채널 타일의 통계다.
Conv1 14,400타일, Conv2 7,500타일. 중첩 타일의 픽셀은 중복 계수된다.
input_zero_percent는 원본 파일 전체의 픽셀 zero율이 아니라 실제 수락된 d 타일 내 비율이다.
Conv2 d는 입력 이미지가 아닌 앞 레이어의 후처리된 activation이다.
현재 회로의 Conv1 공간 처리 범위 최적화도 포함되어 있다.

수학적 근거
T = B^T d, V = T B. B는 가역이므로 V[r,:]=0 iff T[r,:]=0.
T의 네 행은 d0-d2, d1+d2, d2-d1, d1-d3.
현재 unsigned 8-bit 입력, 10-bit T, 11-bit V의 정확한 변환에 대한 결과다.
자유주제 V8 재양자화의 결과로 해석하면 안 된다.
zero_input_pair: 해당 두 입력 행이 모두 영벡터.
nonzero_cancellation: 둘 중 비영 입력 행이 있지만 변환 행이 영벡터.
active: 변환 행에 하나 이상의 비영 값이 존재.
비음수 입력이므로 d1+d2=0은 두 행이 모두 0일 때만 가능하다.
모든 타일에 대해 V 전체=0 iff d 전체=0 또한 확인했다.

핵심 수치 (전체 변환 행을 분모로 사용)
                 Conv1             Conv2
입력 두 행 모두0  56.489583%        52.986667%
비영 입력 상쇄     1.328125%         0.210000%
전체 zero 행      57.817708%        53.196667%
영행 수            33,303            15,959
비영 상쇄 행 수       765                63

타일 전체만 생략하는 경우 대비 행 단위 생략의 추가 기회:
Conv1 57.817708 - 51.048611 = 6.769097 percentage points of row slots.
Conv2 53.196667 - 46.120000 = 7.076667 percentage points of row slots.
이 차이는 비영 상쇄만의 효과가 아니다. 일부 입력 행만 0인 경우도 포함한다.
이는 데이터의 생략 기회이며, 전체 latency 절감률로 직접 환산하면 안 된다.

보고서 권장 서술
"Winograd 변환의 가역성을 이용하여 첫 번째 변환 단계의 zero 행과
최종 변환 영역의 zero 행 사이의 동치 관계를 활용하였다.
고유 입력 100장에 대해 Conv1 및 Conv2의 변환 행 중 각각 57.82%, 53.20%가
생략 가능하였다. 대부분은 영 입력 행 쌍에서 기인했고, 비영 행의 상쇄도
각각 전체 행의 1.33%, 0.21%에서 확인되었다.
따라서 제안 구조는 변환이 sparsity를 증가시킨다고 가정하지 않고,
실제로 존재하는 구조적 sparsity를 정확하게 검출하여 활용한다."

변환 전후 원소 zero율은 Conv1 74.94% -> 65.83%, Conv2 78.94% -> 61.33%.
"변환으로 zero가 대폭 증가한다"는 주장은 이 데이터로 뒷받침되지 않는다.
기존 designated_layers의 zero 타일/행/원소 총계와 동일하다.
에너지 및 사이클 효과는 별도 matched ICG-on 비교 결과와 연결한다.
