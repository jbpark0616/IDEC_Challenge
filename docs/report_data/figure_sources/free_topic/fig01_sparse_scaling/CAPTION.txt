동일한 변환 후 zero-row 비율(50%)에서 텐서 규모와 입력 공급률에 따른 실행 사이클 절감.
입력 표기는 [N,H,W,C]이며 각 입력 아래에는 변환된 U8 가중치의 코어당 용량과 상주 여부를 표시했다.
(a) 코어당 출력8채널, (b) 출력32채널. U SRAM 용량은32KiB이며 초과하는 가중치는 실행 중 재적재한다.
파랑은 타일 입력64-bit word를 매 사이클 제공 가능한 조건, 주황은4사이클당1word 제공 가능한 조건이다.
이는 코어 경계의 통제 공급률이며 외부 DRAM 대역폭을 직접 뜻하지 않는다.
점선은50% MAC-lane 투입량 감소로, 실행시간의 예측치 또는 보장된 상한을 뜻하지 않는다.
모든 수치는 동일 데이터의 sparse OFF 대비 ON이며 초기 적재를 제외하고 실행 중 재적재를 포함한다.
단일 코어 통제 실험이며 실제16코어 VGG 성능이나 전력 감소율로 해석하지 않는다.
