# 보고서 최종 자료

- `designated_topic/`: 지정주제 자료
- `free_topic/`: 자유주제 자료
- 각 주제의 `figures/`, `tables/`, `algorithms/`: 채택한 최종 SVG
- 통합 편집 원본: `designated_topic/IDEC_Challenge_figure.pptx`

이 폴더에는 최종 PPT와 SVG를 보관한다. 생성 스크립트, 중간 PPT, PNG/PDF 미리보기와 버전별 결과물은 쌓아두지 않는다.

측정 원본과 검증 근거는 `../report_data/`에 분리한다. 기존 FIFO 측정 데이터/로그는 `../report_data/designated_fifo_depth/`, 그래프별 수치·조건 자료는 `../report_data/figure_sources/`에 있다.

새 figure는 통합 PPT 마지막에 이어서 작성하고, 승인된 결과만 주제별 폴더에 SVG로 추출한다. 스타일은 `designated_topic/PUBLICATION_FIGURE_STYLE.md`를 따른다.
