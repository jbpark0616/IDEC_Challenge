# Sparsity 제어 면적 비교

최종 계산 코어의 셀 매핑을 유지하고 sparse_enable을 0으로 고정한 비교본을 생성했다. 상수 전파 및 사용되지 않는 논리만 제거하며 ABC 재매핑은 하지 않는다. 커맨드 sparse 래치는 명령 수락 시 0을 샘플하며, QN=1 상태에서 D=0이 유지되는 불변성을 스크립트에서 확인한다. 두 구현의 통제 50% zero-row 입력 출력이 독립 정수 기준과 일치했다. 표본 회귀 검증이며 formal equivalence는 아니다.

SRAM 8개 포함: 35,958.28950 vs 35,752.34700 µm². 추가 면적 205.94250 µm², 비교본 대비 0.5760%. SRAM 제외 기준 1.2205%. ICG는 양쪽에 유지하므로 ICG 자체의 면적 비용을 나타내지 않는다. 고정 셀 매핑의 기능 제거 비교이며 서로 독립적인 전체 RTL 재합성 결과가 아니다. 다른 세 평가 폴더의 전력 비교는 원래 동일 코어의 OFF/ON을 사용한다.

WSL/Linux에서 `python3 reproduce.py`로 재현한다. Yosys 설치 위치는 ORFS_ROOT 또는 YOSYS 환경변수로 지정한다. 사용 Liberty, 비교 넷리스트, 검사 로그와 면적 JSON을 포함했다.
